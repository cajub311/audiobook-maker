Audiobook Maker

This Vercel page is a lightweight launcher for the Python Gradio app in this repository.

Launch locally

pip install -r requirements.txt
python3 audiobook_creator_v7.py

The Gradio app listens on http://localhost:7860. Use the Easy Mobile Mode tab for one-tap generation.

Free cloud memory

Use the app's System tab to back up and restore manifests through JSONBlob (anonymous free JSON storage).

Launch instructions API

Programmatic instructions are available at /api/launch.
