Install on Mobile (PWA)

Android (Chrome)

  1. Open this page in Chrome.
  2. Tap the install banner or browser menu.
  3. Choose Install app.

iPhone / iPad (Safari)

  1. Tap the Share icon in Safari.
  2. Select Add to Home Screen.
  3. Launch from your home screen for app-like mode.

FAQ

Does this run in a mobile browser without installing?

Yes. Install is optional; PWA mode just adds faster launching and better offline launcher caching.

Why did my large PDF fail?

Very large PDFs can exhaust memory/time limits. Split files into smaller chunks when possible.

Can I resume later on another device?

Yes. Enable free cloud memory backup and keep the generated JSONBlob URL for restore.
