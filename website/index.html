FAQ

Does this work offline? +

Yes — the Kokoro offline engine works without internet. EdgeTTS is faster but requires a connection. Easy Mode auto-falls-back to Kokoro on network errors.

What input formats are supported? +

EPUB, PDF, TXT, or any plain text (pasted or from a URL). Output is M4B (chaptered) or MP3.

Can I resume if it stops partway through? +

Yes. Generated segments are cached to disk and reused on restart. Enable "cloud memory" in Easy Mode to sync progress across devices.

What are the file size limits? +

The default upload limit is 500 MB per file, configurable via ABM_MAX_UPLOAD_FILE_BYTES. For very large books, split into parts for best performance.

How do I access this on my phone? +

Run with GRADIO_SHARE=1 for a temporary Gradio share URL, or host on a VPS/cloud machine with a public IP. Use ngrok or cloudflared for tunneling from your local machine.
