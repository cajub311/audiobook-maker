FAQ

Do I need to install anything?

Yes. Run pip install -r requirements.txt and python3 audiobook_creator_v7.py.

Which formats are supported?

EPUB, PDF, TXT. Also paste text or provide a URL.

Is it free?

Yes. Edge TTS and Kokoro are free. Cloud backup uses free JSONBlob.
