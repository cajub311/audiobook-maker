Cost & quota notes (important)
• ElevenLabs bills by character (Turbo ~$0.5–1 per 100k chars on paid plans; free tier has monthly quota).
• A typical novel chapter (~8–15k chars) is usually a few cents. Always check your current quota & pricing at elevenlabs.io/pricing.
• If quota exhausted you will see an auth/quota error — just uncheck the toggle to fall back to free instantly.
• OpenAI TTS is an easy alternative fallback (similar client-side fetch with sk- key) if you prefer their voices.

Tips

  • Free (default): Entirely in-browser via Microsoft Edge neural voices + rich SSML for emotion. No keys, no cost.
  • Premium (toggle above): ElevenLabs — direct client (default, key in localStorage only) or optional secure server proxy (no key in browser when enabled on host via env var). Both fall back instantly to free Edge.
  • Long chapters are auto-split on paragraph & sentence boundaries for cleaner pacing. Same multi-chunk parallel flow for both paths.
  • If generation is slow, lower the parallel request count or the input size.
  • Powerful AI Director: Use 🧠 + Voice Direction field for per-section emotional control via parsed [tags]/keywords applied as overrides in the audiobook items pipeline.
