Frequently Asked Questions

Do I need to install anything to use this?

Yes, you'll need Python 3.9+ and pip to install dependencies locally. However, you can try a demo version without installation (coming soon).

What TTS engines are supported?

Two engines: Edge TTS (cloud, free, faster) and Kokoro (offline, CPU-based). Edge TTS requires internet, while Kokoro works completely offline.

Can I pause and resume generation?

Yes! All projects are saved to disk. You can close the app and resume from where you left off using the "Resume Last Project" button.

What file formats are supported?

Input: TXT, PDF, EPUB, and URLs. Output: MP3 (all chapters in one file) or M4B (chaptered with metadata).

How large a file can I process?

Theoretically unlimited (up to disk/memory), but recommended max is 500MB. Large files may take hours. For best results, keep books under 100,000 words.
